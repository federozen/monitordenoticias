# Diseno del asistente editorial

## Principio

Un solo coordinador ejecuta modulos especializados. Esto evita bots duplicados, reduce el costo y permite explicar cada recomendacion.

## Ciclo

```text
Observar -> agrupar -> verificar evidencia -> priorizar -> sugerir -> informar -> registrar feedback
```

## Salidas

### Recomendacion

Incluye accion, prioridad, confianza, motivo, medios originales, presencia de Ole y evidencia.

### Oportunidad

Incluye formato, angulo, titulo tentativo, esfuerzo y vigencia.

### Informe

Incluye prioridades, huecos de cobertura, temas a verificar, ideas posibles y salud de fuentes.

## Control humano

El agente no publica, no edita produccion, no envia push y no transforma un rumor en confirmacion. El editor decide y registra el resultado.
